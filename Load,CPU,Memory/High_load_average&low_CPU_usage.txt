Check:
1) Disk bottleneck by 
CMD: iostat -xz <sec refresh> 
In that check r/s, w/s, await time and utilization.

2) Too many processes blocked: The standard command to check process state is ps;
 Look for processes with a process status of D (Uninterruptible Sleep/blocked process): ps -aux | awk {'print $8'}

3)  Check memory usage by:
CMD: free -m or vmstat <refresh sec>
