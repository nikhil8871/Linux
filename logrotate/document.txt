The logs are generated by the service systemd-journald and this service is running in background and stores it in /var/log/journal.

rsyslogd: is the service which takes logs from systemd-journald and segregates them as per category and stores it in /var/log/.

logrotate:


Logrotate helps in storing the logs in a single log file and helps to avoid a single log file consuming huge amounts of data.
With the logrotate file we can manage the logs and compress it. Ex if the service like apache is storing the all logs in one file then at the first day the file will be “access.log”.

On the 2nd day, the previous day log will be renamed with access.log1 and the present day will become as access.log.

Similarly on the 3rd day,logs access.log1  rename with access.log2, 2nd day log becomes access.log1 and present day log becomes access.log.

So when the 7th day comes, the access.log will compress.So we have to configure the apache logrotate file present in /etc/logrotate.d/apache2
Note: /etc/logrotate.d is a directory.

The file can be generated day/date wise also.
